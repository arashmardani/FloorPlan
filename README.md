# نمایشگر فضاهای CAD

نسخه اولیه برای فایل‌های مورد اعتماد در محیط داخلی. با Docker و Compose از پوشه پروژه اجرا کنید:

```sh
docker compose up --build -d
```

در مرورگر `http://localhost:8000` را باز کنید. ساخت اولیه اینترنت می‌خواهد؛ پردازش نقشه و نمایش پس از ساخت محلی است. برای توقف `docker compose down` بزنید. گزینه `-v` داده‌های ذخیره‌شده را پاک می‌کند.

## آزمون پذیرش

1. فایل `examples/rooms.dxf` را با واحد «متر» وارد کنید. دو فضا با مساحت ۱۲ و ۶ متر مربع و محیط ۱۴ و ۱۰ متر باید دیده شوند.
2. روی فضای اول کلیک کنید، نام «اتاق جلسه» را بنویسید و ذخیره کنید. همان نشانی (شامل شناسه پس از `#`) را دوباره باز کنید؛ برچسب باید باقی مانده باشد. از لینک JSON برای دریافت اطلاعات استفاده کنید. در خروجی `points` بر حسب واحد ترسیم، `sides` و `perimeter` به متر و `area` به متر مربع هستند.
3. با یک DWG واقعی و اندازه معلوم آزمایش کنید. اگر تبدیل آن نسخه DWG ممکن نبود، از نرم‌افزار CAD خروجی DXF بگیرید. اگر مرز بسته نیست، آن را در CAD به پلی‌لاین بسته تبدیل کنید.

## دامنه نسخه

LibreDWG روی سرور DWG را به DXF تبدیل می‌کند. ezdxf موجودیت‌های سطح اول Model Space را می‌خواند. خطوط و پلی‌لاین‌های مستقیم دوبعدی رسم می‌شوند؛ هر پلی‌لاین بسته و معتبر یک فضای بالقوه است، نه لزوماً یک اتاق. انتخاب واحد به عهده کاربر است. حلقه‌های داخلی از مساحت کم نمی‌شوند. بلوک‌ها، منحنی‌ها، هاشور، متن و اندازه‌گذاری CAD ترسیم نمی‌شوند؛ این نمایشگر جایگزین نمایش کامل AutoCAD نیست. تشخیص اتاق از خطوط پراکنده و خواندن نام‌های موجود در نقشه پیاده نشده است. برچسب توسط کاربر تعیین می‌شود. فایل اصلی تغییر نمی‌کند؛ هندسه استخراج‌شده و برچسب‌ها در SQLite و volume به نام plans باقی می‌مانند. بارگذاری مجدد فایل یک نقشه جدید ایجاد می‌کند.

## استفاده عملیاتی

پورت فقط روی loopback منتشر می‌شود. برای چند کاربر، پیش از انتشار، reverse proxy با HTTPS و احراز هویت و کنترل دسترسی هر نقشه اضافه کنید. شناسه نقشه رمز عبور نیست. این نسخه مدیریت کاربر، سهمیه فضای دیسک، پشتیبان‌گیری و ایزوله‌سازی جداگانه برای هر تبدیل ندارد. برای فایل‌های ناشناس مبدل را در worker محدود و جدا اجرا کنید. برای عیب‌یابی: `docker compose logs viewer`.
